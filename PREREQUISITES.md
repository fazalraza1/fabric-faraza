# ✅ Prerequisites — Setup Checklist

Before running any demos, make sure you have the following ready.

---

## 1. Microsoft Fabric Access
- [ ] You have a Microsoft Fabric-enabled workspace
- [ ] Your account has **Contributor** or **Admin** role on the workspace
- [ ] Fabric capacity is assigned (Trial, F2, or higher)

> 💡 **Don't have Fabric?** Sign up for a free trial at [app.fabric.microsoft.com](https://app.fabric.microsoft.com)

---

## 2. Workspace Setup
- [ ] Create a new Fabric Workspace (e.g., `FabricDemos`)
- [ ] Enable **Fabric items** in workspace settings

**How to create a workspace:**
1. Go to [app.fabric.microsoft.com](https://app.fabric.microsoft.com)
2. Click **Workspaces** in the left panel
3. Click **+ New workspace**
4. Name it `FabricDemos` and click **Apply**

---

## 3. Lakehouse Setup
- [ ] Create a Lakehouse inside your workspace named `BankingLakehouse`

**How to create a Lakehouse:**
1. Inside your workspace, click **+ New item**
2. Select **Lakehouse**
3. Name it `BankingLakehouse`
4. Click **Create**

---

## 4. Files You Need
Each demo folder contains sample data files (CSV). You will upload these during the demo.
No external downloads required.

---

## 5. Recommended Browser
- Microsoft Edge or Google Chrome (latest version)
